Detailed Description

Provides extension methods for ISettingBase<T> and ISettingControl.

Provides a SetIfNotEqual method that only sets the value if it's different from the current value, preventing unnecessary change events and saves.

Parameters
settingThe setting to update.

Returns
true if the value was changed; false if the value was already equal to the current value.

Uses IEquatable<T>.Equals(T) to compare the current value with the new value. Only calls ISettingControl.TrySetValue(KeyOrMouse) if the values differ.
