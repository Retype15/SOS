Detailed Description

Provides logging functionality for the S.O.S mod with support for multiple log levels, conditional compilation (DEBUG/RELEASE), and integrated logger services.

Log output is controlled by ActualLogLevel which defaults to LogLevel.Debug in DEBUG mode and LogLevel.Information in RELEASE mode. Messages with a level below the active threshold are suppressed. Supports optional color coding and integration with Barotrauma's logger services or custom ILoggerService implementations.
