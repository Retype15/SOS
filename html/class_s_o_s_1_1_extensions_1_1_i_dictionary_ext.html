Template Parameters

TThe value type.
Parameters
dictThe dictionary to look up the value in.
keyThe key to look up.
Returns
The value associated with the key, or the default value for T if not found.

Acquires a lock on the dictionary instance before performing the lookup. This only synchronizes callers that also use this helper (or lock the same dictionary instance); it cannot protect writes performed elsewhere.
