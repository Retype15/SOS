Detailed Description

Provides helper methods for configuration management, including loading, saving, and resetting configs.

All operations iterate over configs retrieved via API.GetAllConfigs(). Errors during individual config operations are logged via Logger and execution continues to the next config (no single failure stops the entire operation).

Parameters

Attempts to initialize a configuration setting by name, retrieving it from the config service.

Template Parameters
TThe type of the setting to retrieve; must implement ISettingBase.
Parameters
nameThe name of the configuration setting to look up.
settingWhen this method returns true, contains the retrieved setting; otherwise, the default value for T .
configServiceThe configuration service used to look up the setting.
packageThe content package from which to retrieve the config.
onValueChangedOptional action to invoke when the setting's value changes. Subscribed via ISettingBase.OnValueChanged. In DEBUG mode, also logs the change via Logger.LogDebug.
Returns
true if the setting was successfully retrieved; false if the config was not found.

If the config is not found, a warning is logged via Logger.LogError and false is returned. The onValueChanged delegate is subscribed to the setting's change events, allowing automatic logging or additional processing on value changes.
