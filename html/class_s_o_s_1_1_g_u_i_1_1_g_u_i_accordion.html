Detailed Description

A collapsible container with a chevron icon and a content area.

Consists of a header button with a dropdown-style chevron icon and a content area (GUILayoutBuilder) that can be shown/hidden. The chevron is rotated -90 degrees when collapsed. Toggling triggers layout recalculation on the accordion and its parent layout group.

collapsedWhether the accordion starts collapsed. Defaults to false.
onToggleOptional callback invoked when the accordion is toggled.
iconAnchorThe anchor for the chevron icon. Defaults to CenterRight.

The header component is made non-focusable and wrapped in a transparent button that handles clicks. A chevron icon is created from the "GUIDropDown.dropdownicon" style if available. The content area is a GUILayoutBuilder initially visible based on collapsed . Vanilla pattern: the transform is created outside and passed in (e.g. l.NewDefaultRectTransform()), so the caller owns the parent chain.

void SOS.GUI.GUIAccordion.SetCollapsed ( bool collapsed)

Sets the accordion's collapsed state.

Parameters
collapsedThe new collapsed state.

If the state is unchanged, returns immediately. Updates the chevron icon rotation (-90 degrees when collapsed, 0 when expanded). Shows/hides the content area and the accordion itself. Marks the accordion and its parent layout group (if any) as needing recalculation. Invokes the _onToggle callback if set.
