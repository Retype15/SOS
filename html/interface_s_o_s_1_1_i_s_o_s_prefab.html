Detailed Description

Defines an SOS module acting as an extensible prefab data source that feeds entities into the S.O.S. left sidebar browser.

By implementing this interface and decorating the class with AutoRegisterAttribute, third-party mods can introduce new browsable entity types (such as custom subassemblies, event prefabs, or jobs) into the main S.O.S. interface.

[AutoRegister("MyMod.JobProvider", order: 3.0)]
public class JobPrefabProvider : ISOSPrefab
{
public IEnumerable<Prefab> GetPrefabs(IPrefabFilter filter)
{
return JobPrefab.Prefabs.Where(j => filter.General.All(t => j.Name.Value.Contains(t, StringComparison.OrdinalIgnoreCase)));
}
}

IEnumerable< Prefab > SOS.ISOSPrefab.GetPrefabFavorites ( IPrefabFilter filter)

Yields the favorite prefabs provided by this source that satisfy the specified filter .

Parameters
filterThe structured search filter containing text, category, tag, and mod tokens.
Returns
An enumerable sequence of matching favorite Barotrauma.Prefab instances.

The browser invokes this method before GetPrefabs(IPrefabFilter) so favorites are listed first. The default implementation already keeps the prefabs reported by GetPrefabs(IPrefabFilter) whose identifier satisfies IPrefabFilter.IsFavorite(string), so overriding is only needed when favorites cannot be derived from that query.

Exceptions thrown by an override are logged and the browser continues with the remaining providers.
