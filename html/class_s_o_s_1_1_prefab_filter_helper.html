Detailed Description

Provides helper methods for filtering prefabs based on search criteria.

Contains static methods for matching prefabs against filter criteria. Used by the prefab browser to filter the list of displayed prefabs based on user input.

Checks if a prefab matches the general filter criteria.

Parameters
filterThe filter containing the general search terms.
nameThe prefab's display name.
identifierThe prefab's identifier.
modNameThe mod name the prefab belongs to.
Returns
true if the prefab matches all general filter terms; false otherwise.

If the filter's IPrefabFilter.General list is empty, the method returns true immediately. For each term in the general filter, the method checks if the term is contained in the name, identifier, or mod name (case-insensitive). If any term is not found in any of the three fields, the method returns false.
