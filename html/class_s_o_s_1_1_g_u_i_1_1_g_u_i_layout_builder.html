Detailed Description

A fluent declarative UI builder for creating standard Barotrauma GUI components in a list box.

Extends GUILayoutGroupAuto to provide a fluent API for building UI rows with common patterns: headers, label-value rows, badge rows, selector rows, separators, buttons, text boxes, dropdowns, tick boxes, and sliders. Implements IDisposable to auto-cleanup empty builders or recalculate layout on disposal.

using var builder = new GUILayoutBuilder(listBox);
builder.Header("Section Title", Color.White);
builder.Row("Label:", "Value", Color.Green);
builder.BadgeRow("Tags:", new[] { "tag1", "tag2" });
builder.Button("Click Me", () => Console.WriteLine("Clicked"));
builder.Separator();

◆ Dispose()

void SOS.GUI.GUILayoutBuilder.Dispose ( )

Disposes the layout builder, removing it from its parent if empty or recalculating layout.

If the builder has no children, it is removed from its parent GUIComponent via GUIComponent.Parent.GUIComponent.RemoveChild. Otherwise, Recalculate is called to update the layout geometry of this builder and its ancestors. Calls GC.SuppressFinalize to prevent the finalizer from running, as disposal has already handled all cleanup. This method is safe to call multiple times; subsequent calls after the first are no-ops because the finalizer suppression prevents re-entry.

Adds a row with a label and multiple selectable items (prefabs or prefixed strings) acting as hyperlinks.

Parameters
labelThe label text displayed on the left side.
idsThe item identifiers to display. If null or empty, the method returns null.
displayNamesOptional display names for each identifier. If provided, the count must match ids . If null, the raw identifiers are used as display names.
fallbackFilterPrefixOptional prefix for identifiers that do not resolve to a known prefab.
labelColorOptional color for the label. Defaults to Color.Gray.
onPrimaryCallback invoked on primary click (left mouse button) on a resolved prefab item.
onSecondaryCallback invoked on secondary click (right mouse button) on a resolved prefab item.
onSearchFilterCallback invoked on click of a non-prefab identifier (prefixed string).
Returns
The created GUIButton row, or null if ids is null or contains no elements.

Attempts to resolve each identifier to an ItemPrefab or AfflictionPrefab. Resolved prefabs use their name and icon color; unresolved identifiers use the display name or raw identifier with the fallback prefix and Color.LightSkyBlue color. If only one item is present, the row becomes clickable with a hand cursor and supports both primary and secondary click handlers. The label occupies 40% of the row width and the items occupy 60%.

builder.SelectorRow("Material:", new[] { "iron", "copper" },
displayNames: new[] { "Iron", "Copper" },
fallbackFilterPrefix: 'm',
onPrimary: prefab => SelectMaterial(prefab),
onSecondary: prefab => ShowInfo(prefab));
