Detailed Description

Central helper for managing S.O.S. profile settings windows, navigation history, and tab widgets.

Provides static methods for subscribing to API events, creating and managing the settings window, handling navigation history, creating tab widgets, and drawing configuration settings. Maintains a singleton GUINavigationHistory<Prefab> for tracking prefab selection history.
