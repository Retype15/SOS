Detailed Description

Provides syntax highlighting for XML code strings, coloring nodes, attributes, values, comments, and punctuation.

Uses regular expressions to identify and color different parts of XML syntax. The coloring follows a "Dark Theme" style palette. Note that color tags (‖color:...‖) are protected from being replaced by the punctuation regex.

static

Formats an XML string with syntax highlighting colors.

Parameters
rawXmlThe raw XML string to format. If null or whitespace, returns an empty RichString.
Returns
A RichString with syntax highlighting colors applied.

The formatting performs the following steps:

  1. Escapes the ‖ RichText character to || to avoid parser conflicts.
  2. Highlights string values (text between quotes) using the ColValue color.
  3. Highlights attributes (identifier=) using the ColAttr color.
  4. Highlights node names (<Node>) using the ColNode color.
  5. Highlights punctuation (< > / =) using the ColPunctuation color.
    • Note: To avoid replacing our own color tags (‖color:Hex‖), the regex will not touch anything between ‖ symbols.
  6. Highlights comments (<!– ... –>) using the ColComment color, overwriting any internal colors.

The coloring uses a "Dark Theme" style palette defined as private static readonly fields:

  • ColNode: CornflowerBlue (for node names)
  • ColAttr: LightSkyBlue (for attributes)
  • ColValue: LightSalmon (for string values)
  • ColComment: DarkSeaGreen (for comments)
  • ColPunctuation: LightGray (for punctuation)

Example usage:

var formatted = XMLHighlighter.FormatToXMLCode("<Item identifier=\"test\">value</Item>");
