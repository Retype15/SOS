enum SOS.LogLevel

Severity levels for log messages produced by Logger.

Log levels determine which messages are actually output based on the active ActualLogLevel. Lower numeric values include all higher severity messages (e.g., Error includes Critical). In DEBUG mode, the default threshold is LogLevel.Debug; in RELEASE, it is LogLevel.Information.

Enumerator
None 

No messages are logged.

Critical 

Critical messages that indicate a fatal failure.

Error 

Error messages indicating a problem that needs attention.

Warning 

Warning messages indicating a potential issue.

Information 

Informational messages about normal operation.

Debug 

Debug messages for development-time diagnostics.

Trace 

Trace messages for detailed diagnostic output.
