Detailed Description

A resizable and draggable frame component with configurable resize directions and bounds clamping.

Supports mouse-based resizing from edges and corners, with optional symmetric resizing (Shift), aspect ratio preservation (Shift on corner), and parent bounds clamping. Also supports dragging the frame by its title area (top 50px by default).

◆ Update()

override void SOS.GUI.GUIResizableFrame.Update ( float  deltaTime)

Updates the frame, handling mouse interactions for resizing and dragging.

Parameters
deltaTimeTime elapsed since the last update in seconds.

Handles three interaction states:

  • Idle:Detects hover over resize edges/corners (within ResizeMargin) or title area. Updates cursor to indicate available interaction.
  • Dragging (resizing):Resizes the frame based on mouse movement. Supports corner resizing with aspect ratio preservation (Shift), symmetric resizing (Shift on edge, Alt for temporary symmetric), and parent bounds clamping.
  • Moving:Moves the frame by dragging the title area (top DragAreaHeight pixels). Ignores interactive child elements (buttons, text boxes, dropdowns, list boxes).
