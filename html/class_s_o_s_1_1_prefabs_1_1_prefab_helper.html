Detailed Description

Provides static methods for managing favorite prefabs.

Maintains a HashSet<T> of favorite prefab identifiers. Provides methods for adding, removing, and toggling favorites. Optionally emits a CommKeys.RefreshSearch event after modifications to notify UI components of changes.
