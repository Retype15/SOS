Detailed Description

A tabbed interface container for displaying multiple tabs, each handling a specific type of item.

Template Parameters
TThe type of item that tabs can handle.

Manages a list of ITab<T> instances, providing a button bar for tab selection and a content area for the active tab. Tabs are filtered by their ITab<T>.CanHandle method. Each tab owns a dedicated content frame and button, both created once in RegisterTab and stored alongside the tab; the widget owns their visibility exclusively.

string  id 
)

Registers a tab with the tab container.

Parameters
tabThe tab to register.
idThe registration identifier of the tab. Used for localization and selection history.

Creates the owned content frame, asks the tab for its button via ITab<T>.CreateTabButton, calls ITab<T>.Init, wires the click handler once, stores all four in the internal list, and catches up with ITab<T>.Update when a valid target already exists. If initialization throws an exception, the created frames are discarded, the error is logged via Logger, and the tab is ignored.

◆ UpdateTabs()

void SOS.GUI.GUITab< T >.UpdateTabs ( T  target)

Updates the tab list for a new target item, filtering tabs by their ITab<T>.CanHandle method.

Parameters
targetThe new target item to display.

Broadcasts the target to every tab via ITab<T>.CanHandle, falls back ActiveTab when it no longer applies, flips stored content and button visibility, then rebuilds the active tab only via ITab<T>.Update. If there's only one valid tab, the button area is hidden and the content area fills the full height.
