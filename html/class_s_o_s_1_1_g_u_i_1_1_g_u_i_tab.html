Detailed Description

A tabbed interface container for displaying multiple tabs, each handling a specific type of item.

Template Parameters
TThe type of item that tabs can handle.

Manages a list of ITab<T> instances, providing a button bar for tab selection and a content area for the active tab. Tabs are filtered by their ITab<T>.CanHandle method.

void SOS.GUI.GUITab< T >.UpdateTabs ( T  target)

Updates the tab list for a new target item, filtering tabs by their ITab<T>.CanHandle method.

Parameters
targetThe new target item to display.

Clears the button area and rebuilds it with tabs that can handle the target. If the current active tab can't handle the new target, the first valid tab is selected. If there's only one valid tab, the button area is hidden and the content area fills the full height.
