Detailed Description

Represents parsed search criteria used by ISOSPrefab.GetPrefabs(IPrefabFilter) to filter entities in the browser.

Supports advanced search prefixes parsed by PrefabFilterHelper.SearchFilter:

  • </term>Filters by Content Package / Mod Name (Mod).
  • #Filters by Category enum string (Category).
  • $Filters by item or affliction tag (Tag).
  • &Filters by equipment slot string (Slot).
  • !Filters by exact or partial identifier string (ID).
  • %Filters by Prefab type name (PrefabType).
