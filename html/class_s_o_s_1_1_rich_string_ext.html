Detailed Description

Rich text formatting extension methods utilizing Barotrauma's native RichText formatting tags.

Barotrauma requires the specific Unicode double vertical bar character ‖ (\u2016) as the tag delimiter. Standard ASCII pipe characters (|) are not recognized by the engine and will render as raw text.

Formats produced:

  • Color: ‖color:R,G,B‖text‖end‖ or ‖color:ColorName‖text‖end‖
  • Style: ‖bold‖text‖end‖, ‖italic‖text‖end‖, ‖underline‖text‖end‖, ‖strikethrough‖text‖end‖
