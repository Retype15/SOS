Detailed Description

Defines an interchangeable visual presentation layout for the S.O.S. window.

Implementations inherit from GUI.GUIWindow and define how the screen space is partitioned (e.g., 3-column browser view, compact single-column inspector, or floating HUD tool).

Hot-Swapping: Profiles can be changed dynamically at runtime via API.Emit<T>(string, T, double?, bool) using CommKeys.ChangeProfile. When switching profiles, the outgoing profile is disposed and the incoming profile is instantiated, initialized via Init, and opened seamlessly.
