◆ ResizeDirection

enum SOS.GUI.ResizeDirection

Flags indicating which edges/corners of a frame can be resized.

Used by GUIResizableFrame to determine which resize handles are active. Can be combined using bitwise OR (e.g., ResizeDirection.Top | ResizeDirection.Right).

Enumerator
None 

No resize directions allowed.

Top 

Can resize from the top edge.

Bottom 

Can resize from the bottom edge.

Left 

Can resize from the left edge.

Right 

Can resize from the right edge.

Horizontal 

Can resize horizontally (left and right edges).

Vertical 

Can resize vertically (top and bottom edges).

All 

Can resize from all edges and corners.

◆ WindowButtons

enum SOS.GUI.WindowButtons

Flags controlling which system buttons are displayed in the window header.

Use bitwise OR to combine flags (e.g., WindowButtons.Minimize | WindowButtons.Close). Default is All.

Enumerator
None 

No system buttons.

Minimize 

Show minimize button.

Maximize 

Show maximize/restore button.

Close 

Show close button.

MinClose 

Show minimize and close buttons.

MaxClose 

Show maximize and close buttons.

All 

Show all system buttons (default).
