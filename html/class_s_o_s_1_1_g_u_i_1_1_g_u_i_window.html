Detailed Description

Standardized resizable window with a fixed top bar (toolbox, title, custom and system buttons) and a content area that fills the remaining vertical space.

Inherits from GUIResizableFrame providing drag-to-move and edge-resize functionality. The window consists of:

  • TopBar:Fixed-height header containing title, toolbox, and system buttons.
  • ToolBox:Left area for custom controls (32% width).
  • ControlBox:Right area for custom controls (60% of right area).
  • SystemBox:Rightmost area for system buttons (minimize, maximize, close).
  • ContentArea:Fill-area below the header for window content.

System buttons (minimize, maximize, close) are created based on the WindowButtons flags. The window supports two modes: WindowMode.Windowed (default) and WindowMode.Fullscreen. In fullscreen mode, the window fills its parent rect and resizing is disabled.

var window = new GUIWindow(
new RectTransform(new Point(600, 400), GUI.Canvas, Anchor.Center),
"My Window Title",
style: "InnerFrame",
buttons: WindowButtons.All,
mode: WindowMode.Windowed);
window.ToolBox.AddChild(new GUIButton(...));
window.ContentArea.AddChild(new GUIListBox(...));
window.Open();

rectTThe rectangle transform defining initial position and size.
titleTextThe window title text.
styleGUI style name. Defaults to "InnerFrame".
colorOptional background color.
buttonsSystem buttons to display. Defaults to WindowButtons.All.
modeInitial window mode. Defaults to WindowMode.Windowed.

The constructor builds the complete window structure:

  1. TopBar with fixed height DefaultHeaderHeight.
  2. Title centered in TopBar.
  3. ToolBox (left, 32%) and RightArea (right, 20%) with ControlBox (60%) and SystemBox (40%).
  4. System buttons based on buttons flags.
  5. ContentArea below header, auto-sized on resize.
