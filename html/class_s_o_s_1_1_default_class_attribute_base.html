Detailed Description

Base attribute for default class resolution in DuckProxy.

This attribute is used by DuckProxy<T> to resolve fallback methods when a target method or property is not directly found on the adapted object. The fallback resolution chain is:

  • Parameter-based lookup:Gets the method's parameter types and searches for a matching static method on the helper type.
  • Property-based lookup:If the interface method is a property getter, searches the declaring type's properties for a matching getter.
  • Type-level fallback attribute:Searches the declaring type or its parents for a DefaultClassAttributeBase decoration.
