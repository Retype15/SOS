Detailed Description

Specifies a static helper class containing fallback method implementations for interface contracts adapted by DuckProxy<T>.

When a Lua table or external CLR object lacks an interface method or property getter, DuckProxy<T> searches the static helper type declared by this attribute for a public static method matching the interface signature.

This attribute must be applied to the interface definition or individual interface properties, pointing to the helper type.

[DefaultClass(typeof(MyServiceDefaults))]
public interface IMyService
{
int GetValue();
}
public static class MyServiceDefaults
{
public static int GetValue() => 42;
}
// If luaTable lacks "GetValue", DuckProxy routes the call to MyServiceDefaults.GetValue():
var service = DuckProxy<IMyService>.Create(luaTable);
