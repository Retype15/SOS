Detailed Description

Primary static facade providing access to S.O.S. mod extensibility points, SOS module registries, prioritized event dispatching, and shared runtime state.

Architecture:

  • SOS Module Registries: Manages SOS modules: sections (ISOSStatInfo), tabs (ISOSTab), configs (ISOSConfig), prefab providers (ISOSPrefab), and window profiles (ISOSWindowProfile) with ordering and activation control.
  • Prioritized Event Pipeline: Provides thread-safe event publishing and subscription (On, Off, Emit) ordered deterministically across EventPriority tiers.
  • Shared State: Offers a lightweight, reactive key-value state store (SetState<T>(string, T, bool), GetState<T>(string)) for cross-mod communication.

Thread-Safety & Reentrancy: Internal registry mutations are synchronized via monitor locks. Event callbacks execute outside internal locks, ensuring safe reentrant invocations and zero deadlocks.

// Registering an SOS module:
API.RegisterTab(typeof(MyCustomTab), "MyMod.CustomTab", order: 10.0);
// Listening to target selection events:
API.On<Prefab?>(CommKeys.SelectTarget, target =>
{
Logger.LogDebug($"Target selected: {target?.Identifier}");
}, EventPriority.UI);
// Reading shared state:
var currentTarget = API.GetState<Prefab?>(CommKeys.SelectTarget);
