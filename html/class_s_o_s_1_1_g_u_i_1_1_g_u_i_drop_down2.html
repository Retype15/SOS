Detailed Description

A custom dropdown component with support for single/multiple selection, keyboard navigation, and custom styling.

Modified from the Barotrauma base GUIDropDown to add multi-select support, improved keyboard handling, and custom list box positioning. Supports both single and multiple selection modes with tick boxes.

Creates a new dropdown component.

Parameters
rectTThe rectangle transform for positioning and sizing.
elementCountThe number of visible elements in the dropdown list. Defaults to 4.
styleThe GUI style name. Defaults to empty string.
selectMultipleWhether to enable multiple selection mode with tick boxes. Defaults to false.
dropAboveWhether the dropdown list should open above the button. Defaults to false.
listBoxWidthOptional fixed width for the dropdown list. Defaults to parent width or button width.
expandToRightWhether the list should expand to the right. Defaults to auto-detect based on anchor.

Creates a button with "GUIDropDown" style and a list box positioned relative to the button. In single-select mode, clicking an item selects it and closes the dropdown. In multi-select mode, tick boxes are used and MustSelectAtLeastOne can enforce at least one selection. The list box is attached to the highest parent in the GUI hierarchy for proper rendering.
