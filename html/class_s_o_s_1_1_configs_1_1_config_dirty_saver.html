Detailed Description

A unit-of-work base class that buffers configuration modifications and persists only changed settings to disk.

Modified settings are tracked within _dirtySettings. Changes are only written to persistent storage when SaveChanges is explicitly invoked (typically on window closure or round completion). This pattern prevents redundant file I/O operations during interactive UI adjustments.
