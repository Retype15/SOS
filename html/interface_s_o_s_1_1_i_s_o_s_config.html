Detailed Description

Defines a modular prefab inspection tab (type alias for ITab<T> where T is Barotrauma.Prefab).

Defines an extensible configuration unit with lifecycle persistence, factory defaults, and declarative UI rendering.

Implementations are managed through API and integrate with Configs.ConfigDirtySaver to buffer changes and persist them safely using Barotrauma's LuaCs config service.

Lifecycle Methods:

  • Load:Invoked during client startup (Configs.ConfigHelper.LoadConfigs) to load saved values into memory.
  • Save:Invoked on window dismissal or round transitions to serialize modified values to disk.
  • Reset:Restores all settings managed by this unit to their default values.
  • DrawSettings:Constructs the interactive configuration UI in the settings window using GUI.GUILayoutBuilder.
[AutoRegister("MyMod.Settings", order: 5.0)]
public class MyModSettings : ConfigDirtySaver, ISOSConfig
{
public void Load() { /* ... <em>&zwj;/ }
public void Save() { /</em> ... <em>&zwj;/ }
public void Reset() { /</em> ... *&zwj;/ }
public bool DrawSettings(GUIListBox container)
{
using var l = new GUILayoutBuilder(container);
l.Header("MY MOD CONFIG", Color.Gold);
l.ButtonToResetSection(this);
return true;
}
}
