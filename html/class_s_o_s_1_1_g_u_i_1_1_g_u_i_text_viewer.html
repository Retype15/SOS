Detailed Description

A zoomable, scrollable rich-text viewer with syntax highlighting support.

Extends GUITextBlock with horizontal and vertical scroll bars, zoom functionality (Ctrl+Mouse Wheel), and horizontal scrolling (Shift+Mouse Wheel). Supports context menus via the ContentMenu event on right-click.

Parameters

Initializes the viewer with overflow clipping, no text wrapping, and focus enabled. Creates horizontal and vertical scroll bars with the "GUIScrollBar" style. Subscribes to size and scale changes to trigger scroll bar recalculation.

Parameters
componentStyleThe style to apply. If null, the method returns without changes.

Captures the style's padding as the original padding for later use in scroll bar layout. Ensures text color is visible (defaults to white if transparent or black). ◆ Update()

override void SOS.GUI.GUITextViewer.Update ( float  deltaTime)

Updates the viewer, handling scroll bar recalculation, zoom, scrolling, and context menu interactions.

Parameters
deltaTimeTime elapsed since the last update in seconds.
  • Recalculates scroll bars if needed.
  • Handles right-click to invoke ContentMenu.
  • Handles Ctrl+Middle Mouse to reset zoom to 0.9x.
  • Handles Ctrl+Mouse Wheel for zoom (clamped to MinScale and MaxScale).
  • Handles Shift+Mouse Wheel for horizontal scrolling.
  • Handles Mouse Wheel for vertical scrolling.
  • Updates TextOffset based on scroll bar positions.
