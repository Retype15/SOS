Detailed Description

A layout group that automatically recalculates its preferred height based on its visible children.

This GUILayoutGroup arranges its children in a vertical flow, summing the heights of all visible children plus the absolute spacing between them, plus a 10-pixel bottom padding. The Recalculate method is called whenever GUILayoutGroup.NeedsToRecalculate is true, typically after a child's state changes.

Lifecycle: Recalculation occurs during Update; this component is not thread-safe and should only be used on the GUI thread.

new bool SOS.GUI.GUILayoutGroupAuto.Recalculate ( )

Recalculates the layout group's preferred height based on visible children.

Returns
true if the preferred MinSize changed; false otherwise.

Sums the heights of all visible children plus GUILayoutGroup.AbsoluteSpacing between them, plus 10 pixels of bottom padding. Updates RectTransform.MinSize and RectTransform.MaxSize. If the size changed and the parent is a GUILayoutGroup, marks it as needing recalculation.

Thread safety: Must only be called from the GUI thread; this component is not thread-safe.
