Detailed Description

Provides localized text lookup with fallback support for S.O.S mod.

Texts are resolved via TextManager.Get(string) with an optional fallback string. In DEBUG mode, fallbacks are prefixed with "[NT]" (NOT-TRANSLATED) to identify missing translations. The result is cached by prefix for performance via GetTranslationsByPrefix.

// Basic usage with fallback
var text = Texts.Get("sos.some_key", "Fallback text if not found");
// Get all translations starting with a prefix
var translations = Texts.GetTranslationsByPrefix("sos.");

Gets a localized string by key with an optional fallback.

Parameters
keyThe localization key to look up.
fallbackThe fallback string to use if the key is not found.
forceFallbackIf true, returns fallback directly without lookup.
Returns
The localized string if found; otherwise fallback (prefixed with "[NT]" in DEBUG).

In DEBUG builds, missing translations are prefixed with "[NT]" to highlight untranslated content. In RELEASE builds, the raw fallback is returned without the prefix. If fallback is null or empty, returns the result from TextManager.Get(string) directly.

Gets all translations matching the specified prefix, with caching.

Parameters
prefixThe key prefix to filter translations by.
Returns
A dictionary mapping localization keys (Identifier) to their translated values, filtered to keys that start with prefix .

Results are cached in prefixCache for subsequent calls with the same prefix. The cache is populated by querying TextManager.GetAllTagTextPairs on first access. Returns an empty dictionary if no translations match the prefix.
