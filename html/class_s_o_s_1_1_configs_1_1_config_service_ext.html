Detailed Description

Writes a batch of dirty settings to disk using a single read/modify/write cycle per content package.

LuaCs' SaveConfigValue reloads, parses and rewrites the whole settings file for every individual setting, turning a window close into dozens of synchronous disk operations on the update thread. This saver groups the dirty settings by their owning package and performs one load plus one save per package, producing the exact same XML layout as the vanilla per-setting path.
