Detailed Description

Instructs the S.O.S. discovery engine to automatically register the decorated class into its corresponding API factory.

During mod first opening (API.Initialize), the LuaCs plugin management service scans loaded assemblies for classes decorated with this attribute that implement one of the core extension interfaces:

  • ISOSTab (or ITab<T>): Registered as a browser tab.
  • ISOSStatSection: Registered as an inspector wiki section.
  • ISOSPrefab: Registered as a prefab data provider in the browser.
  • ISOSWindowProfile: Registered as a visual window layout profile.
  • ISOSConfig: Registered as a reactive configuration unit.

Deferred Instantiation: Decorating a type with this attribute registers its factory delegate without constructing an instance immediately. Actual construction is deferred until the component is first requested by the user or the active profile.

[AutoRegister("MyMod.RadiationSection", order: 5.0, active: true)]
public class RadiationSection : ISOSStatSection
{
// ...
}
