Detailed Description

Instructs the S.O.S. discovery engine to automatically register the decorated class as an SOS module into its corresponding API factory.

An SOS module is any class implementing one of the core ISOS* contracts (ISOSTab, ISOSStatInfo, ISOSPrefab, ISOSConfig, ISOSWindowProfile).

During mod first opening (API.Initialize), the LuaCs plugin management service scans loaded assemblies for classes decorated with this attribute that implement one of the SOS module contracts:

  • ISOSTab (or ITab<T>): Registered as an SOS module acting as a browser tab.
  • ISOSStatInfo: Registered as an SOS module acting as an inspector wiki section.
  • ISOSPrefab: Registered as an SOS module acting as a prefab data provider in the browser.
  • ISOSWindowProfile: Registered as an SOS module acting as a visual window layout profile.
  • ISOSConfig: Registered as an SOS module acting as a reactive configuration unit.

Deferred Instantiation: Decorating a type with this attribute registers its factory delegate without constructing an instance immediately. Actual construction is deferred until the SOS module is first requested by the user or the active profile.

[AutoRegister("MyMod.RadiationSection", order: 5.0, active: true)]
public class RadiationSection : ISOSStatInfo
{
// ...
}
