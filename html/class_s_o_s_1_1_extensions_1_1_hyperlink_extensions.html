Detailed Description

Provides methods for binding hyperlinks to GUI text blocks and joining enumerable items to rich strings.

Contains extension methods for creating rich text strings with clickable hyperlinks and for binding those hyperlinks to GUI components's click areas.

Template Parameters

Parameters
textBlockThe text block to which click areas will be added.
itemsThe items to bind hyperlinks for.
onPrimaryClickThe action to invoke when a hyperlink is primary-clicked.
onSecondaryClickOptional action to invoke when a hyperlink is secondary-clicked.

The method iterates over the RichTextData of the text block and adds clickable areas corresponding to each item. Clickable areas store the data and invoke the appropriate click handlers. If onSecondaryClick is not provided, secondary clicks are ignored.

Joins an enumerable of items into a single RichString, applying color formatting to each item.

Template Parameters
TThe type of items in the enumerable.
Parameters
itemsThe items to join.
separatorThe separator string between items.
textSelectorA function that selects the text for each item.
colorSelectorA function that selects the color for each item.
Returns
A RichString containing all items with color formatting applied.

Each item's text is formatted with its corresponding color using the RichString.SetColor(string) pattern. The ‖ symbol is used as the RichText color tag delimiter. The original ‖ characters in the text are removed (replaced with empty string) to avoid breaking the RichText parser.
