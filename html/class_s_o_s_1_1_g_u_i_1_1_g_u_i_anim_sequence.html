Detailed Description

Manages a chain of sequential and parallel animations for a GUIComponent.

Uses a step-based parallel execution model:

  • Each chained method adds an action to the current "step" (parallel block).
  • WaitFinish seals the current step; subsequent animations wait for it to complete.
  • Wait(float) inserts a timed delay as its own step.
  • All coroutines are driven by CoroutineManager.

The sequence auto-starts on construction via CoroutineManager.StartCoroutine. Original colors/alphas are captured at construction for fade/restore operations.

component
.ExFadeIn(0.3f)
.Wait(0.5f)
.ExShake(0.2f, 8f)
.ExLerpColor(Color.Red, 0.3f)
.Execute(() => Logger.LogDebug("Done!"))
.ExFadeOut(0.2f);
