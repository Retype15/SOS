# SOS Modules (ISOS Interfaces) (#sos_modules)

> [!TIP]
> Un módulo SOS es cualquier clase que implemente alguna interfaz `ISOS*` (`ISOSTab`, `ISOSStatInfo`, `ISOSPrefab`, `ISOSConfig`, `ISOSWindowProfile`).

Para crear sus propios módulos SOS, necesita registrarlos vía `[AutoRegister]` o `API.Register*`. Ver: [Registration](registration.html).
