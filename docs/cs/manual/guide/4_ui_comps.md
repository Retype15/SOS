# UI and GUI Components {#ui_comps}

## 4. Ventanas y pestañas

- **GUIs personalizados:**
  - **GUIWindow:** Componente que permite la creación rápida y gestión general de ventanas redimensionables con barra de título, cajas de herramientas y componentes varios. Es una abstracción de `GUIResizableFrame`
  - **GUITab:** Componente para la creacion de componentes `ITab` para la navegación por pestañas.
  - **GUILayoutBuilder:** Una clase helper para construir layouts declarativos, responsivos y flexibles para listas ordenadas. fáciles de mantener y gestionar.
  - Y otros que veremos más adelante.
